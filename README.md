## Proyecto Principal: ZENIN
**Motor de Inferencia Activa y Riesgo Estocástico**

ZENIN es una arquitectura metacognitiva diseñada para operar bajo incertidumbre extrema. Originalmente concebido para telemetría IoT industrial, hoy opera como un orquestador agnóstico de toma de decisiones.

| Arquitectura | Implementación |
| :--- | :--- |
| **Metacognición** | Ecuación Maestra v2.2 que evalúa el `CVaR` y la sincronía temporal antes de ejecutar órdenes. |
| **Zero-Latencia** | Infraestructura asíncrona desacoplada (`asyncio`, adaptadores de memoria compartida). |
| **Memoria Vectorial** | Integración nativa con `Weaviate` para recuperación de estados y regímenes históricos. |
| **Full-Stack** | Telemetría en vivo vía `WebSockets` y panel de control interactivo en `React JS`. |
